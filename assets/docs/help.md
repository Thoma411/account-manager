# Keeledger 使用帮助

> 一个零知识加密的账号密码管理器。本文档介绍常用功能与注意事项。

## 快速上手

### 首次使用：创建保险箱

1. 首次打开应用会进入空库引导页，点击 **"创建新数据库"**；
2. 设置**主密码**（不少于 6 位）并确认；
3. 应用会为你生成一串**恢复密钥（RK）**——请务必妥善保存（建议复制到安全的地方），**这是忘记主密码后找回数据的唯一凭证**，一旦丢失将无法恢复数据；
4. 创建完成后即可开始添加账户条目。

### 解锁保险箱

- 老用户打开应用后需输入主密码解锁；
- 解锁后数据密钥（DK）仅在内存中生效，锁定 / 退出应用后立即清除。

### 忘记主密码怎么办？

1. 在解锁页点击 **"忘记主密码？"**；
2. 输入你事先保存的**恢复密钥**进行验证；
3. 验证通过后设置新的主密码，应用会生成**新的恢复密钥**，请再次妥善保存；
4. 也可以在设置页 **"查看恢复密钥"** 随时查看当前密钥，或用 **"重置恢复密钥"** 主动更换。

## 界面说明

### 账户列表

- 顶部搜索框支持**多关键词搜索**（用空格分隔多个词，需全部命中，不区分大小写）。可搜索的字段：平台名、昵称、账号、邮箱、网址、备注、标签；
- 桌面端按 `Ctrl+F` 快速聚焦搜索框，`Esc` 退出搜索；
- 排序：右上角排序按钮可切换 **"按平台名称"** 或 **"按修改时间"**，并支持升降序切换；
- 字母索引条：点击字母可跳转到对应拼音首字母的条目。

### 账户卡片

- 每条卡片显示：1.平台图标（自动抓取或首字母占位）、2.平台名、3.昵称 / 账号、4.邮箱 / 手机、5.标签、6.状态色条（移动端仅显示2和6）；
- 点击卡片查看详情：桌面端在右侧滑出详情面板，移动端进入全屏详情页。

## 账户管理

### 新增账户

- 桌面端点击右下角 **"+"** 按钮，移动端点击列表页右上角添加图标；
- 必填项：**平台名称**；此外至少填写一项关键信息（昵称 / 账号 / 密码 / 邮箱 / 手机）；
- 平台名称不可重复（不区分大小写）；
- 点击 **"填写更多信息"** 可展开附加字段：网址、标签、状态、生日、注册日期、实名标记、备注；
- 标签最多 8 个，用逗号分隔。

### 编辑 / 删除

- 进入详情页后点击铅笔图标进入编辑模式，修改后点击对勾保存；
- 详情页提供复制密码、删除条目等功能。

### 账户状态

| 状态 | 含义 |
| ------ | ------ |
| 未注册 | 已创建条目，但未注册该平台 |
| 使用中 | 可正常登录、或正在使用的账号 |
| 已注销 | 经本人手动注销的账号 |
| 无法使用 | 由于种种原因无法登录的账号 |

新增的条目如未指定，状态默认为"使用中"。

### 自动抓取图标

- 设置页开启 **"自动抓取图标"** 后，应用会根据平台网址自动获取网站图标并缓存到本地；
- 可在设置页 **"清除图标缓存"** 一键清理。

## 云同步

### 配置 WebDAV（目前仅适配了坚果云）

1. 在坚果云客户端：设置 → 特色功能 → **第三方应用管理** → 添加应用密码（名称任意），生成密码；
2. 在应用内：设置 → **云端 WebDAV 配置**，依次填写服务器地址、账号、应用密码，测试连接并保存；
3. 前往 **"云同步"** 页面管理备份。

### 智能同步

应用通过比较本地修订号与云端 ETag 判断哪端更新：

- 仅本地改动 → 自动上传；
- 仅云端改动 → 拉取下载（完成后需重新解锁载入）；
- 两端都有改动（冲突）→ 弹出选择框，由你决定**保留本地**或**保留云端**。

**"强制上传 / 强制下载"** 可绕过判断直接执行。

### 静默同步

- 设置页开启 **"静默同步"** 后，应用会在**登录时自动下载**、**退出 / 关闭时自动上传**最新数据。

### 同步日志

- 云同步页面会记录最近 15 条同步操作（含设备信息），可手动清空。

## 导入导出

### 导出为 CSV

- 设置 → **导出为 CSV**。**注意：导出的是明文文件**，任何拿到该文件的人都能看到全部密码，请在安全环境操作并妥善保管或及时销毁。

### 从 CSV 导入

- 设置 → **从 CSV 导入**。支持 13 列标准格式（与导出格式一致），**重复的平台名会被自动跳过**。

| 列号 | 字段含义 | 字段名 |
| ------ | ---------- | -------- |
| c1 | 平台名 | platform |
| c2 | 用户昵称 | name |
| c3 | 用户ID | user_id |
| c4 | 邮箱 | email |
| c5 | 密码 | pswd |
| c6 | 网址 | url |
| c7 | 手机号 | phone |
| c8 | 生日 | birth |
| c9 | 备注 | notes |
| c10 | 注册日期 | signup_date |
| c11 | 实名标记 | real_name |
| c12 | 标签 | tags |
| c13 | 状态 | status |

## 安全机制

- **零知识加密**：你的主密码不会上传到任何服务器，所有数据在本地加密；
- **加密算法**：AES-256-GCM；主密码经 PBKDF2（SHA-256，10 万次迭代）派生密钥；
- **信封加密**：数据密钥（DK）分别由主密钥（MK）和恢复密钥（RK）封装，DK 仅在解锁后驻留内存；
- 敏感字段（昵称、账号、密码、邮箱、手机、备注）均加密存储；平台名、网址等非敏感字段明文存储以便检索。

## 常见问题

**Q：更换设备如何迁移数据？**
A：导出 CSV → 新设备创建保险箱 → 导入 CSV；或配置好云同步后，在空库引导页选择 **"从云端恢复备份"**。

**Q：账户数量有限制吗？**
A：单个保险箱最多 **4096** 条，应该够一般人使用了吧我寻思。

**Q：为什么搜索不到某些条目？**
A：搜索采用"全部命中"模式（多个关键词需同时满足），且只覆盖平台名、昵称、账号、邮箱、网址、备注、标签这几个字段；可尝试减少关键词数量。

**Q：如何反馈问题或建议？**
A：设置 → **反馈与建议**，进入 GitHub Discussions 参与讨论。
